# Life-DCG α版

雨 唐衣さまの小説『俺の切り札は光らない』（ハーメルン・カクヨムで連載）に登場するカードゲーム「Life」を、
パソコンで遊べるようにした **一ファンによる非公式の二次創作** です。原作者さまの公認を受けた作品ではありません。

- 対応: Windows のパソコン
- 料金: 無料
- 版: α版（開発途中の版です）

## ダウンロードの手順（GitHub を使ったことがない方も大丈夫です）

GitHub のアカウントや、専門の道具は要りません。ブラウザでファイルを1つダウンロードするだけです。

1. このページの右側（スマホでは下の方）にある **「Releases」** を押します。
2. いちばん上の版の **「Assets」** の中にある `LifeDCG-alpha-（版）-（日付）.zip` を押すと、ダウンロードが始まります。
   - 「Source code (zip)」と「Source code (tar.gz)」はゲームではありません。押さないでください。
3. ダウンロードした ZIP を右クリックして **「すべて展開」** を選び、デスクトップなどの好きな場所に展開します。
   - ZIP を開いただけでは起動できません。必ず展開してください。
4. 展開したフォルダの中にある **`LifeDCG-DEMO.exe`** をダブルクリックすると、ゲームが始まります。

### 「Windows によって PC が保護されました」と表示されたら

このゲームは個人が作ったもので、Microsoft の署名を受けていません。そのため、初めて起動する時に青い画面が出ることがあります。ウイルスが見つかったという意味ではありません。

1. 画面の **「詳細情報」** を押します。
2. 表示された **「実行」** を押します。

不安な場合は、実行せずに閉じてください。

### ダウンロードしたファイルが本物か確かめたい方へ（任意）

Releases には、ZIP と同じ名前の `.sha256` ファイルも置きます。中に書かれた英数字の列（ファイルの指紋）が、手元の ZIP から求めた値と一致すれば、ファイルは途中で書き換えられていません。PowerShell で次のように確かめられます。

```
Get-FileHash .\LifeDCG-alpha-（版）-（日付）.zip -Algorithm SHA256
```

## 遊び方

- まずはタイトル画面の **チュートリアル** を選んでください。様々なタイプの初期同梱デッキのデッキですぐに遊べます。
- 詳しい遊び方は、ZIP に入っている **「はじめての方へ.md」** をご覧ください。
- 標準デッキは18種類入っています。（なおバランスは調整中となります）
- 自分でカードを作りたい方は、ゲーム内の **「デッキ構築 ＆ 刻字作業」** と、ZIP に入っている **「Lifeカード作成キット」** をご覧ください。

- OS: Windows 10 / 11（64ビット）
